# FLEURS Danish playback clips

These 50 short clips are from the Danish test split of [Google FLEURS](https://huggingface.co/datasets/google/fleurs), released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). They correspond to the examples selected for transcript comparison on the Danish ASR Leaderboard. The original WAV audio was converted to mono 16 kHz AAC in M4A containers for browser playback; the speech content was not edited.

Source: Conneau et al., [*FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech*](https://arxiv.org/abs/2205.12446), 2022. The source dataset and its authors are credited here under CC BY 4.0.

`manifest.json` binds each clip ID to its exact benchmark reference. The player only displays a clip when that reference still matches the comparison data.
